# Us, on the server

Drop Minecraft screenshots (PNG or JPG) and clips (MP4) in here. Both the old
ones of the two of you and the ones from the wedding. They appear on
10months.html by themselves, under the vows, about two minutes after you
commit. There is no code to edit.

They show in filename order, so name them 1.png, 2.png and so on if you want a
particular order. Otherwise the raw Minecraft names sort by date on their own.

Screenshots are saved by F2, into the screenshots folder of whichever
instance you are playing.
