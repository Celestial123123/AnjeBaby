# Letters

One file per day, numbered in order:

    01.txt  ->  day one, 9 October
    02.txt  ->  day two
    03.txt  ->  day three

Write the next one and drop it in here. It appears on the page that day. There
is no list to update and nothing to tell anyone.

The page reads forward from 01 and stops at the first number that is missing,
so the numbers have to run without a gap. If 04 is not there, 05 will not show
even if you upload it.

Writing ahead is fine. Anything numbered beyond the day she has reached stays
hidden until that day arrives.

The flower gains a petal for each one. Twenty nine is a full bloom.

Line breaks are kept exactly as you type them.
