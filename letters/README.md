# Letters

A numbered list. One is released each day, in order, starting from the START
date set in rose.html.

    01.txt  ->  day one
    02.txt  ->  day two

Nothing is tied to a calendar date, so you can rewrite any single letter for
something that happened that day without disturbing the rest of the run.

Add more by carrying on the numbering. If the list runs out, the last one
stays up until you add another.

The flower gains a petal for each letter that has opened. Twenty nine is a
full bloom.

Line breaks are kept exactly as you type them.
